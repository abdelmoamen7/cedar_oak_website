# Cedar & Oak Cleaning Company

Premium single-page website for Cedar & Oak Cleaning Company — residential and commercial cleaning serving Hamilton County, Indiana (Carmel, Fishers, Westfield, Noblesville).

## View the site

Open `index.html` in your browser. No build step required.

## Structure

```
cedar_oak_website/
├── index.html
├── css/styles.css
├── js/main.js
├── assets/
│   └── logo.png          ← official Cedar & Oak logo
└── README.md
```

- Sticky header + mobile menu
- Grand Opening $30 OFF promo
